# File Nodes

文件节点是 React Flow 的第二类节点。

- `CreateFileDialog` 可新建空白文件，也可通过系统“浏览”批量选择现有文件。选择现有文件后沿用原文件名和后缀，只选择隔离/共享范围以及复制/引用；从画布拖入的文件因浏览器拿不到可信原路径而固定使用复制模式。
- 画布拖放支持一次导入多个文件，节点从鼠标落点开始依次错开放置；浏览器 `File` 只在导入弹窗的临时状态中存在，不会进入持久化布局。
- 复制文件进入 Canvas 项目的文件目录；引用文件留在原位置，并以只读方式提供给 Agent。引用失效时节点提供“重新定位”，不显示写 Handle 或全局写开关。
- 后缀名使用普通输入框，不限制选项；服务端统一规范化后缀并决定文本、Markdown、CSV、图片或不预览。
- `FileNode` 展示文本、Markdown、CSV 和图片预览；其他格式只显示文件名。
- Agent 调用 `report_result` 后会生成带来源元数据的结果文件节点，复用同一套文本/Markdown/CSV/图片预览，并自动连接到产生结果的对话轮。
- 点击文件节点的内容区域或标题栏外链按钮，会通过后端用 VS Code 打开真实文件，不区分文件格式。
- 标题栏眼睛按钮打开 `FileContentWindow`：文本读取完整内容，图片显示原图，其他二进制格式提示改用 VS Code。
- 普通节点左侧 `write` 是输入端，右侧 `read` 是输出端。
- 共享节点不使用连线，通过“全局读/全局写”开关授权全部 Agent。这里的共享是画布文件节点共享，会把隔离目录中的文件引用传给 Agent；它不同于 branch workspace 的共享资源映射。
- 文件节点标题栏使用 `.drag-handle`，可与对话节点一样在画布中拖动；重命名只能通过铅笔按钮进入，避免误触。
- 文件节点支持四边/四角拖拽缩放，缩放尺寸由 React Flow 节点状态保存。
- 文件节点支持最小化/恢复；最小化只改变同一 React Flow 节点的尺寸和外观，保留 `read/write` Handle，已有连线不会断。
