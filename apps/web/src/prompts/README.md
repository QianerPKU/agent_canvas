# Prompt Nodes

提示词节点是画布中的纯文本上下文节点。

- 普通节点通过读写连线绑定 Agent；共享节点通过全局读写开关授权全部 Agent。
- 读权限不会传文件引用，而是把文本直接拼接到 Agent 的用户输入之前。
- 注入时机只有新建 Agent 的首轮，以及手动或自动 compact 完成后的下一条业务输入。fork 首轮不重复注入，因为会话上下文已继承。
- 多个可读节点固定按“共享优先、普通其次；同类按 UTF-8 编码顺序”排列。
- 写权限让 Agent 编辑服务端内部文本载体，画布每两秒同步最新内容。
- 标题栏使用 `.drag-handle` 拖动画布节点；名称只通过铅笔按钮进入重命名输入，避免点击标题边缘时误触。
- 提示词节点支持四边/四角拖拽缩放，正文 textarea 会随节点尺寸扩展。
